What's included

A standard one-zone install

This price is for a new ductless mini split that serves one zone. It is not a replacement of equipment already in the home. A typical install includes the items below. The free in-home estimate confirms anything else before work is scheduled.

Indoor and outdoor units

One indoor unit and one outdoor unit for a single zone.

New line set and drain

A new refrigerant line set and a condensate drain between the units.

Mounting and the opening

Mounting for the new equipment, plus the wall opening, sealing, and line routing for a first-time install.

Startup and cleanup

Startup, a short walkthrough of the controls, and cleanup of the work area.
